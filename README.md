# ESP32-CAM monitoring system

Камера на ESP32-CAM с PIR-датчиком движения. При движении в кадре плата делает фото и отправляет его в Telegram-бот. Фото можно запросить и вручную.

## Железо

| Компонент | Подключение |
|---|---|
| ESP32-CAM (AI Thinker) | — |
| PIR-датчик (HC-SR501 или аналог) | OUT → GPIO13, VCC → 5V, GND → GND |
| Вспышка | встроенный светодиод на GPIO4 |

Для прошивки нужен USB-UART адаптер (или плата ESP32-CAM-MB): GPIO0 замкнуть на GND на время загрузки.

## Настройка

1. Создай бота через [@BotFather](https://t.me/BotFather) и получи токен.
2. Узнай свой chat_id, например через [@userinfobot](https://t.me/userinfobot).
3. Скопируй `Vision/secrets.example.h` в `Vision/secrets.h` и впиши Wi-Fi, токен и chat_id. Файл `secrets.h` в `.gitignore` и в репозиторий не попадает.

## Сборка

**PlatformIO** (рекомендуется, версии платформы и библиотек зафиксированы):

```
pio run -t upload
pio device monitor
```

**Arduino IDE**: открыть `Vision/Vision.ino`, плата «AI Thinker ESP32-CAM», ядро esp32 версии 2.0.x, библиотеки UniversalTelegramBot и ArduinoJson 6.x. С ядром 3.x код пока не собирается (другой API watchdog).

## Команды бота

- `/start` — справка
- `/photo` — сделать фото сейчас
- `/flash` — включить или выключить вспышку

Бот отвечает только chat_id из `secrets.h`.

## Надёжность

- Если Wi-Fi пропал, плата переподключается каждые 10 секунд, не перезагружаясь.
- Если при старте не удалось подключиться за 30 секунд, плата перезагружается.
- Watchdog перезагружает плату, если основной цикл завис больше чем на 60 секунд.
